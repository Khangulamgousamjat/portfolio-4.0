## 🌌 Overview

**Portfolio 4.0** is an interactive, cyberpunk-inspired personal portfolio web application and interactive command center. Built from the ground up for **Gulamgous Khan** (Full Stack AI/ML Engineer), it transitions away from generic portfolio templates into an ultra-fast, visually striking digital workspace.

### Core Philosophy
* **Zero Heavy Framework Overhead**: Built with pure semantic HTML5, modern vanilla CSS3 (cyber glassmorphism, scanline overlays, neon glow tokens), and vanilla ES6+ JavaScript.
* **Dual Runtime Flexibility**: Can be deployed immediately as a static web application on any CDN/hosting provider or run as a full-screen Python **Streamlit** app with dynamic asset bundling.
* **Futuristic Neural Aesthetics**: Includes a custom 60 FPS HTML5 Canvas particle physics engine, responsive HUD elements, glitch hover effects, and an interactive Linux terminal emulator.

---

## ✨ Key Features & Subsystems

### 1. Neural Particle Constellation Engine
* Custom **HTML5 Canvas** particle network running at a butter-smooth 60 FPS.
* Dynamic node clustering, edge connections based on proximity, and interactive mouse attraction/repulsion physics.
* Automatically pauses or resizes dynamically according to the user's viewport dimensions.

### 2. Interactive Cyber Terminal (CLI Emulator)
* Embedded bash-inspired terminal emulator (`guest@neural-core:~$`).
* Supports command parsing, interactive history buffer, auto-scroll, prompt restoration, and quick-command pill buttons.
* Includes custom Easter eggs, help manuals, status telemetry, and ANSI-colored responses.

### 3. Dynamic Tech Matrix & Real-Time Filtering
* Categorized skill registry covering:
  * **AI / GenAI**: LangChain, LLMs, RAG, PyTorch, TensorFlow, OpenCV, NLP.
  * **Full Stack**: React.js, Next.js, TypeScript, Node.js, Express, FastAPI.
  * **Databases & Vector Stores**: PostgreSQL, MongoDB, Redis, Pinecone, ChromaDB, FAISS.
  * **Cloud & DevOps**: Docker, AWS, GCP, Git, GitHub Actions, Linux/Bash.
  * **CS Foundations**: C++, OOP, Data Structures & Algorithms.
* Instant DOM-based tab filtering with smooth transition animations.

### 4. Interactive System Architecture Tree
* An expandable ASCII architecture tree showing the structural mapping between Full Stack Development, AI/ML Engineering, Data Layers, and DevOps pipelines.

### 5. Curated Production Projects Showcase
* Interactive project cards featuring:
  * Dynamic status indicator badges (Pulse animation).
  * Direct repository links and external documentation overviews.
  * Category toggle between **All**, **AI / GenAI**, and **Full Stack** projects.

### 6. AI Subsystems & Live Telemetry HUD
* Status monitoring panels indicating the readiness of OpenAI API, Gemini API, Prompt Engineering modules, and Multi-Agent Orchestration networks.
* Career mission tracker highlighting focus areas: LeetCode mastery (200+ solved), Agentic AI, and target Google SWE preparation.

### 7. Real-Time GitHub & LeetCode Coding Pulse
* Live telemetry widgets pulling real-time statistics directly from GitHub:
  * Overall repository contributions and top languages.
  * GitHub commit streak counter.
  * Dynamic Tokyo-Night themed contribution activity graph.
  * LeetCode achievement metrics (200+ solved across DP, Graphs, Binary Search, Sliding Window).

### 8. Transmission Protocol (Contact & Copy System)
* Transmission terminal contact form with real-time field validation.
* One-click direct email copy with floating cyber toast alerts.
* Direct access links to LinkedIn, GitHub, and LeetCode profiles.

## 💻 Cyber Terminal Command Matrix

The portfolio comes equipped with an interactive terminal in the hero section. Visitors can type commands directly or click the quick-command chips:

| Command | Arguments | Output Description |
| :--- | :--- | :--- |
| `help` | None | Displays list of all available terminal commands and utilities |
| `status` | None | Returns engineer identity, role, mission, DSA milestones, and targets |
| `skills` | None | Prints breakdown of specialized AI, Full Stack, Data, and Cloud tech |
| `projects`| None | Lists featured production repositories with high-level descriptions |
| `stats` | None | Returns LeetCode metrics, GitHub telemetry, and system uptime |
| `contact` | None | Displays official transmission links (Email, LinkedIn, GitHub, LeetCode) |
| `whoami` | None | Prints the current session privilege level (`guest@neural-core`) |
| `sudo` | None | Security challenge returning administrator access restriction |
| `matrix` | None | Runs a simulated neural data stream and binary kernel sequence |
| `clear` | None | Flushes the terminal buffer and restores default prompt |
